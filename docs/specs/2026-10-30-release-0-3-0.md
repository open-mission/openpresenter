# Spec — Versão 0.3.0: Controle Remoto Mobile, Saída Lower Third, PWA e Ícone Nativo do Executável

## Contexto e Intenção

Após a consolidação dos novos módulos do OpenPresenter Minimal — **Controle Remoto Mobile (`/remote`)**, **Saída Lower Third Transparente para OBS/transmissão (`/lower-third`)**, **Suporte a PWA** para instalação em celulares e computadores, e **Ícone Nativo do Executável** —, o projeto atinge maturidade suficiente para um salto de versão menor (**v0.3.0**) sob os preceitos de Semantic Versioning (SemVer).

Além disso, atende-se ao requisito explícito do usuário para que o executável gerado em todas as plataformas (Windows, macOS e Linux) possua o ícone oficial do OpenPresenter incorporado ao arquivo executável e à interface nativa do sistema operacional (Finder, Explorer, Dock e barra de tarefas).

---

## Escopo da Versão 0.3.0

### 1. Unificação da Versão (`0.3.0`)
- Atualização em `Cargo.toml` (`[workspace.package] version = "0.3.0"`).
- Atualização em `frontend/package.json` (`"version": "0.3.0"`).
- Atualização em `.github/workflows/release.yml` (tags e fallbacks `v0.3.0`).
- Atualização em `frontend/src/lib/components/SettingsModal.svelte`.
- Promoção das alterações acumuladas no `CHANGELOG.md` para a versão oficial `## [0.3.0] - 2026-10-30`.

### 2. Ícone Oficial no Executável (Windows, macOS e Linux)
- **Windows (`.exe`):**
  - Manutenção e validação do recurso PE via `winresource` embutindo `assets/branding/open-presenter-app-icon.ico`.
- **macOS (`.app` e binário Mach-O):**
  - Geração do arquivo oficial `assets/branding/open-presenter-app-icon.icns` multi-resolução Retina (16x16 até 1024x1024).
  - Script oficial de empacotamento `scripts/package-macos.sh` que gera o pacote de aplicativo nativo `OpenPresenter.app` com `Info.plist` e `.icns`.
  - Atribuição do ícone oficial diretamente no arquivo binário Mach-O (`open-presenter`) através dos atributos do Finder (`com.apple.FinderInfo` e `ResourceFork`), garantindo que o arquivo avulso exiba o ícone no Finder e na área de trabalho.
  - Chamada em tempo de execução no `main.rs` para configurar o ícone da aplicação no Cocoa `NSApplication`, assegurando exibição na Dock e no App Switcher (Cmd+Tab).
- **Ativos de Marca:**
  - Registro de `open-presenter-app-icon.icns` e `open-presenter-app-icon-1024.png` no `assets/branding/README.md`.

### 3. Novas Funcionalidades Consolidadas na v0.3.0
- **Controle Remoto Mobile (`/remote`):**
  - Navegação móvel por abas (**Setlist**, **Músicas**, **Bíblia**).
  - Navegador bíblico com sub-abas em grade (Livros, Capítulos de 44px, Versículos).
  - Input Group e Drawer Shadcn UI para seleção de traduções bíblicas.
  - Projeção contínua de versículos com navegação Anterior/Próximo e contagem correta de slides.
  - Parser canônico de músicas (`parseRawLyrics`) preservando estrofes por linhas em branco.
  - Card de controle ao vivo retrátil (collapsible).
  - Estados ativos com destaque verde esmeralda "Ao Vivo".
  - Safe-area no iOS e Android (top e bottom).
- **Saída Lower Third Transparente (`/lower-third`):**
  - Fundo com canal alfa nativo para Browser Source no OBS Studio e vMix.
  - 4 temas visuais: Gradiente Central, Barra Inferior, Caixa Flutuante e Minimalista.
  - Aba de configurações dedicada com prévia interativa 16:9.
- **Progressive Web App (PWA):**
  - Manifesto web (`manifest.webmanifest`), Service Worker (`sw.js`), ícones 192 e 512, e meta tags standalone para instalação em celulares e computadores.

## Critérios de Aceite

1. `cargo check` e `cargo test --workspace` rodam com sucesso reportando a versão `0.3.0`.
2. `cd frontend && npm run check && npm run build` compilam com sucesso sem warnings.
3. O binário no macOS e o arquivo `.exe` no Windows possuem o ícone oficial do OpenPresenter.
4. O script `scripts/package-macos.sh` gera o `OpenPresenter.app` e aplica o ícone no binário.
5. `CHANGELOG.md` registra a v0.3.0 com a data atual e abre uma nova seção `## [Unreleased]`.
6. Todos os portões de qualidade (`cargo fmt`, `clippy`, `test`) passam sem qualquer violação.
